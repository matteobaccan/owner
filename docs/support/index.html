Getting support

If you need help, have a question, or want more detail on how to use OWNER, everything happens on GitHub:

  • Discussions — questions, ideas, “how do I do this”, “is this supposed to work like that”. Start here if you are not sure something is a bug.
  • Issues — bug reports and feature requests.
  • This documentation site, and the Javadoc for the detail it does not cover.

Please ask in the open rather than by email to the maintainer. It is not a matter of preference: a question answered in a discussion is found by the next person who has it, and an answer sent privately helps exactly one person and is lost. Others may also know the answer sooner than the maintainer does.

The Telegram chat is closed

A Telegram group was announced in 2018 and ran for some years. It is closed, and the invitation links to it still scattered around the web go nowhere. Use Discussions instead.
