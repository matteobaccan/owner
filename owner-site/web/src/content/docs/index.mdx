## See how it works

Put your settings in a properties file, exactly as you already do:

```properties title="ServerConfig.properties"
port=80
hostname=foobar.com
maxThreads=100
```

Declare an interface next to it, and let OWNER do the wiring:

```java title="ServerConfig.java"
import org.aeonbits.owner.Config;

public interface ServerConfig extends Config {
    int port();
    String hostname();

    @DefaultValue("42")
    int maxThreads();
}
```

Then read your configuration as typed values, with no loading code at all:

```java
ServerConfig cfg = ConfigFactory.create(ServerConfig.class);
System.out.println("Running on " + cfg.hostname() + ":" + cfg.port());
```

That is the whole thing. No `Properties` object to load, no `getProperty()` call
to spell out, no string to parse into an `int`.
